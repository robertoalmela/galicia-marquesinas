# Marquesinas de Galicia - Dossier Profesional Web

## 📋 Descripción

Sitio web profesional desarrollado como dossier de presentación del proyecto **"Marquesinas de Galicia: Memoria, Territorio e Identidad"** destinado a la Xunta de Galicia, Diputaciones Provinciales, Ayuntamientos y otras instituciones públicas.

## 🎯 Objetivo

Presentar de forma profesional, atractiva e institucional el proyecto de documentación fotográfica y preservación del patrimonio arquitectónico de las marquesinas de autobús de Galicia.

## 🚀 Cómo Usar

### Visualización Local
1. Abrir `index.html` directamente en cualquier navegador moderno
2. No requiere servidor web para funcionar localmente

### Subir a Servidor Web
1. Subir toda la carpeta `web_dossier` al servidor
2. Configurar dominio para apuntar a `index.html`
3. Verificar que las rutas de imágenes sean correctas

### Requisitos del Servidor
- **Hosting:** Cualquier hosting web estático
- **Dominios recomendados:** 
  - marquesinasdegalicia.es
  - marquesinasgalicia.gal
  - patrimoniogalicia.org

## 🔧 Modificaciones Futuras
